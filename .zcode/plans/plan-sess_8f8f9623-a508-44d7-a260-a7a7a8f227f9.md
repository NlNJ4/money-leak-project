# Dashboard Charts: Category Donut + Daily Spending Bars

Goal: make spending visible at a glance. The dashboard answers "where did money go" (category bars) and "what happened recently" — but not "when did I overspend" or "give me composition at a glance". This plan adds two charts in a natural reading order: **summary cards → donut (where) → daily bars (when) → recent list**, all driven by the existing period filters and bilingual i18n.

## Step 1 — SQL: daily totals in `dashboard_summary`
- New migration `20260829000009_dashboard_daily_totals.sql`: `CREATE OR REPLACE FUNCTION dashboard_summary` — same as current, plus a `dailyTotals` json array built with `generate_series(p_from, p_to)` LEFT JOINed to the user's expense transactions, so **days with zero spending appear as 0** (needed for an honest time axis). Each entry: `{ "date": "YYYY-MM-DD", "expense": number }`, ordered by date. SECURITY INVOKER, RLS applies — same pattern as the existing aggregation.
- Mirror the SQL into `supabase/migrations/` locally and apply via Supabase MCP.

## Step 2 — Data plumbing
- `types/database.types.ts`: no shape change needed (function still returns `Json`).
- `lib/transactions.ts`: `DashboardData` gains `dailyTotals: { date: string; expense: number }[]`; `getDashboardData` passes it through from the RPC result.

## Step 3 — Chart library
- `pnpm add recharts` (v3 — React 19 compatible, responsive, easy to style).

## Step 4 — Donut chart (`components/dashboard/category-donut.tsx`, client)
- Recharts `PieChart` with inner radius (donut), **expense composition only** (income stays in the summary cards — spending focus).
- **Center overlay**: period total expense + the localized word for "expense" (e.g. `฿12,400 / รายจ่าย`).
- **Legend** beside (desktop) / below (mobile): icon + localized name + % + amount per slice — so no color-guessing.
- Fixed categorical palette for slice colors; empty state when no expenses in range.
- This **replaces** the old horizontal `CategoryCard` bars (they show the same information less prettily).

## Step 5 — Daily bars (`components/dashboard/daily-chart.tsx`, client)
- Recharts `BarChart`: one bar per day in the selected range, expense amounts, zero-filled days.
- X axis: day numbers (ticks thinned automatically for long custom ranges); Y axis minimal; Tooltip with `formatCurrency` ฿ amounts; rose-toned bars to match the expense color language.
- Full width under the donut; works with all four period filters including custom ranges.

## Step 6 — Wire into the dashboard + i18n
- `dashboard-view.tsx`: donut + legend where `CategoryCard` was; `DailyChart` full-width below the cards grid; `RecentCard` unchanged; delete the old bar implementation.
- `lib/i18n/dictionaries.ts`: add a few keys (`dashboard.charts.daily` "รายวัน / Daily spending", empty-state text); everything else reuses existing keys.
